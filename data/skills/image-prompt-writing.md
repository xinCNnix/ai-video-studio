# 生图提示词写法（源自 github.com/freestylefly/awesome-gpt-image-2）

## 何时用
generate_scene_image / generate_image 之前，先把场景描述转成结构化生图提示词，不要直接丢分镜原文（分镜文本是给视频模型的时间线描述，含运镜动词，直接用会污染构图）。

## 提示词六段结构（按序拼装）
1. **主体与任务**：谁/什么在做什么，一句话锁死。
2. **构图与布局**：景别（特写/半身/全景）、机位角度（平视/俯拍/低角度）、主体位置（居中/三分线）、画幅。
3. **视觉风格与材质**：写实照片 / 3D 渲染 / 扁平插画 / 水彩 / 电影感；材质与光线（柔和窗光/黄昏逆光/霓虹夜景）。
4. **画面文字**：需要出现在图里的文字必须逐字给出并加引号；不需要文字时明确"画面中不出现任何文字"。
5. **输出格式**：宽高比、分辨率倾向。
6. **负面约束**：多余手指、扭曲面部、水印、乱码文字、拼贴感。

## 模板匹配优先级（按用途选模板再填内容）
产品图 → 海报/封面 → UI 截图/界面 → 信息图/知识卡片 → 品牌视觉 → 摄影写实 → 角色设定 → 场景概念图。

关键模板要点：
- **海报**：锁定主视觉+标题层级，明确"单张成品海报，非拼贴展示板"。
- **UI 截图**：锁定平台（手机/网页）、状态栏、Tab、操作区等 UI 元素，文字逐字给出。
- **信息图**：3-5 个模块上限，短标签+箭头+留白，禁止长段正文入图。
- **角色设定**：正面+侧面多视图或单张定妆照，锁定服装/发型/配色以便跨分镜一致。
- **场景概念图**：交代空间纵深（前景/中景/背景）与光源方向。

## 各模型差异
- **image-01 (MiniMax)**：强项写实人像与人物特征；支持单张人像参考图（type=character，
  最佳效果为单人正面照），参考图一致性弱于 Nano Banana Pro，提示词写"保持参考人物的长相特征"；
  提示词用自然语言长句，写清情绪与光影；英文提示效果更稳。
- **Nano Banana Pro (gemini-3-pro-image)**：零样本一致性最强，多参考图融合写法："keep the same character/person as the reference"。
- **Seedream 4.5/5.0**：4K 与文字渲染强，中文提示词友好，海报/信息图首选。
- **gpt-image-2**：指令遵循最强，六段结构全给即所得，支持逐字长文本渲染。
- **flux-2-pro**：写实与光影质感强，不懂超长指令，提示词保持 100 词内、少提文字渲染。
- **qwen-image**：中文文字渲染好，海报中文标题可选它。

## 分镜 → 生图转换规则
- 删掉运镜动词（推、拉、摇、移、跟）——那是视频术语，改为静态构图描述。
- 时长/转场/旁白信息一律不进提示词。
- i2v 分镜的关键帧 = 该镜首帧画面：取动作起点瞬间的静态构图。
- 同一项目跨分镜保持一致：重复使用同一段角色与风格描述（文字完全相同），不要每次改写。
