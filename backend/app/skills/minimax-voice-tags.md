# MiniMax TTS 台词格式化（云端模型专用）

MiniMax 台词文本支持三类内联标记 + 标点韵律。**标记之外的一切文字都会被照读**
（中文括号、舞台指示、Higgs `<|…|>` 标签、导演备注），所以转格式 = 只留能念的字 + 合法标记。

## 标记目录（仅这三类合法）

**停顿 `<#x#>`**：x 为秒数，范围 [0.01, 99.99]，最多两位小数。
- 必须夹在两段可发音文本之间（前后都得有要念的字），不可连续使用两个停顿标记
- 常用 0.2–0.8（语气缓冲）、1.0–1.5（悬念/转折）；更长的停顿宁可拆段

**语气词标签（半角英文括号）**：仅 speech-2.8-hd / speech-2.8-turbo 支持，
其他模型会把括号内容当英文念出来，用前先确认模型：
(laughs) 笑 / (chuckle) 轻笑 / (sighs) 叹气 / (gasps) 倒吸气 / (breath) 换气 /
(pant) 喘气 / (inhale) 吸气 / (exhale) 呼气 / (coughs) 咳嗽 / (clear-throat) 清嗓子 /
(sniffs) 吸鼻子 / (sneezes) 喷嚏 / (groans) 呻吟 / (snorts) 喷鼻息 / (burps) 打嗝 /
(lip-smacking) 咂嘴 / (humming) 哼唱 / (hissing) 嘶声 / (emm) 嗯。
放在动作发生的确切位置，如 `我说过多少次了(sighs)<#0.6#>算了。`

**行内注音（半角小括号）**：普通话拼音带声调 1–5、粤拼带声调 1–6 或 IPA，
用于纠正多音字/专有名词：`这是(he2)平，不是(huo4)面。` 只注有歧义的字，不整句注音。

## 韵律主要靠标点，不靠标记

停顿长度 逗号 < 分号 < 句号/问号/叹号 逐级加长；省略号自带迟疑感；换行 = 段落切换。
标点能表达的停顿不写 `<#x#>`，`<#x#>` 只用于标点给不出的时长（如节拍点、长悬念）。

## 情绪的正确表达方式

- **整段情绪**：语音面板的 Emotion 控件（请求级参数：happy/sad/angry/fearful/
  disgusted/surprised/calm/fluent/whisper，其中 fluent/whisper 仅 2.6 系可用），
  不写进台词。语速、音高同理走控件。
- **MiniMax 没有句内情绪标签**：`<#happy#>` 之类不存在，编造会被念出来。
- **句内语气变化** = 语气词标签（需 2.8 模型）+ 停顿 + 标点的组合；
  同一句前半喜后半悲这种真·情绪翻转，只能拆成两条分别选情绪合成，不要硬塞一条。

## 台词转换流程（用户给台词 → 输出 MiniMax 格式）

1. **剥杂**：删 Higgs `<|…|>` 标签；舞台指示按语义转换（"（笑着说）"→`(laughs)`，
   转不了的直接删）；清理多余空格
2. **分段**：按语义换行（换行即段落切换）
3. **断句**：把一逗到底的长句断好——这是自然韵律的主要来源，比任何标记都重要
4. **加标记**：仅当用户点名要停顿/换气/叹气/笑时注入；拿不准就不加
5. **交付**：先给可直接粘贴进配音台本的台词块（用代码块包裹、纯文本），
   再用一两句话说明加了什么标记、为什么

## 使用守则

1. **默认零标记**：2.8 系模型会按文本自动安排情绪与停顿，过度标记反而机械。
   用户的台词若无表现力诉求，只做剥杂 + 分段 + 断句。
2. **密度上限**：停顿约每 3 句最多 1 个；语气词整篇 ≤3 个。
3. **长度**：单条 <10000 字符；超 3000 字符建议拆条（流式由系统处理，无需关心）。
4. **仅对 MiniMax 有效**：目标若为本地 Higgs / 小米 / OpenAI TTS，必须剥掉这些标记
   （Higgs 的对应能力见 higgs-voice-tags）。
