# 分镜剧本写作方法论

## 核心理念
分镜剧本不是"把故事切成几段"，而是**用镜头控制观众的注意力与情绪曲线**。每个分镜必须回答：这一镜让观众获得什么新信息/新情绪？删掉它叙事是否受损？答不上来就该合并或删除。

## 开场钩子（前 2 秒定生死）
竖屏短视频观众 1.5 秒内决定去留。分镜 0 禁止缓慢环境铺垫，必须：
- 悬念钩：直接展示反常画面（"皮肤上正在消失的色块"）
- 冲突钩：人物困境瞬间（女孩盯着镜子里的白斑，手在抖）
- 提问钩：旁白直接抛问题（"白斑会传染吗？"）
环境交代要么压进钩子镜的前 1 秒，要么延后到情绪建立之后。

## 信息释放曲线
科普/治疗类内容的分镜序列按"情绪 → 认知 → 行动"三层递进：
1. **情绪层**（1-2 镜）：共情主角困境，建立"这和我有关"
2. **认知层**（2-4 镜）：每镜只讲一个知识点，视觉化抽象概念（免疫细胞攻击黑色素细胞 = 卡通小人推倒色素砖块），知识密度前低后高
3. **行动层**（1 镜）：明确下一步（就医/复诊/心态），给观众出口
禁忌：一镜塞两个知识点；结论先于过程给出。

## 镜头经济性
- 单镜只做一件事： EITHER 讲清一个动作，OR 展示一个奇观，OR 传递一个情绪
- 每镜必须有**画面变化驱动力**：主体动作、镜头运动、或光线变化，三者至少其一持续存在，否则观众 2 秒内划走
- 默认时长 4-6s；只有钩子镜与高潮镜值得 6-8s，过渡镜压到 3-4s

## 转场设计
相邻分镜之间必须有视觉/逻辑衔接，拒绝硬切堆砌：
- 动势转场：上一镜主体移出方向 = 下一镜主体移入方向
- 相似形转场：圆形白斑 → 圆形细胞 → 圆形药片（微观/宏观切换的黄金手法）
- 声音先入：下一镜旁白/音效提前 0.5s 进入
- 情绪对比转场：焦虑特写 → 明亮全景（压抑→释然的节奏拐点）

## 旁白节奏
- 单镜旁白 ≤ 2 句、每句 ≤ 15 字，口语化，禁止书面语堆砌
- 旁白与画面错位配合：画面演具象，旁白说抽象（画面：细胞大战；旁白：原来是我们自己的免疫系统认错了人）
- 关键句放分镜末尾 1 秒（钩住下一镜），疑问句后必须紧跟解答镜

## 蒙太奇结构模板（按需选用）
- **AIDA**：注意（钩子）→ 兴趣（困境）→ 欲望（原理揭示）→ 行动（就医引导）
- **问题-放大-解法-证明**：白斑出现 → 误解与恐惧放大 → 治疗原理 → 恢复案例收尾
- **三幕微结构**：设定（5-8s）→ 对抗（15-20s，2-4 镜）→ 解决（5-8s）

## 角色设定卡（一致性之锚——拆分镜前必做）
每个出场角色先写设定卡，30-60 字可直接用于生图与视频 Subject：
- **要素**：体型比例（头身比）、轮廓形状、主色+辅色（具体色名）、材质质感、服装/配饰、标志性特征（触角/眼镜/疤痕等）、年龄感与表情基调
- **示例**：小墨=深棕色Q弹小精灵，2.5头身比圆胖体型，圆脸大眼，头顶两根短触角，皮克斯式柔润次表面散射材质，无服装，虚弱时触角低垂
- **一致性铁律**：每镜 prompt 的 Subject 段必须**逐字复述**所用角色设定卡的关键特征（禁止只写角色名"小墨"——视频模型不认识名字）；跨镜服装/配色/材质不得漂移
- 多角色同镜时全部复述，并写明空间关系（左/右/前/后）

## 生成方式决策（每镜必标 gen_mode）
- **i2v 图生视频（默认）**：凡有明确主体/角色出场的镜头。流程=先生成该镜关键帧图（引用角色设定图），再以关键帧为首帧生成视频——这是多镜一致性的根本保障
- **t2v 文生视频**：仅限抽象/纯环境/粒子光效/无角色特征一致性需求的镜头（如大远景空镜、光斑流转）
- 每镜另写 keyframe_prompt（关键帧图描述：该镜构图+景别+角色姿态+光线，引用设定卡），供 generate_scene_image 使用
- 镜头 0 若生成"角色设定图"（多视角/表情参考），该图成为后续所有分镜的 reference

## 镜内时间轴（每镜独立，禁止全局时刻）
- 每个分镜是一条独立生成的视频：Action Timeline 一律以**该镜首帧为 0 时刻**（0-2s / 2-4s…），各时间段之和 = 该镜时长
- 剧本中的全片绝对时刻（如"3\"-7\""）只可留在分镜表备注供总控参考，**绝不能写进该镜 Prompt**
- 违例后果：视频模型按全局时刻排动作，该镜前几秒空白或动作被压缩

## 分镜自检清单（create_scenes 前逐条过）
1. 每个出场角色都有设定卡了吗？每镜 Subject 都逐字复述设定特征了吗？
2. 每镜都标注 gen_mode 了吗？i2v 镜都写 keyframe_prompt 了吗？
3. 分镜 0 在 2 秒内抛出钩子了吗？
4. 有没有一镜塞了两个知识点？
5. 每镜画面都有持续的变化驱动力吗？
6. 相邻分镜的转场设计了吗（动势/相似形/声音先入/情绪对比）？
7. 旁白每句 ≤ 15 字、与画面错位配合了吗？
8. 结尾给观众行动出口了吗？
9. 总时长与内容量匹配（竖屏科普 30-45s，即 6-9 镜）？
